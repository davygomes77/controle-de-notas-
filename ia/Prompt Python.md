# Prompt Python

Este projeto utiliza como diretriz pedagógica o prompt original recebido para a atividade. A versão arquivada é `Prompt Python-1.md`.

A aplicação segue as regras principais: Python com Tkinter/ttk, paradigma procedural, vetor de nomes, matriz `5 x 3` de notas, validação, uso explícito de sequência, seleção e repetição, além de mensagens de erro com `messagebox`.
